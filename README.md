# 故宮探險家

用國立故宮博物院開放資料做的 K-12 教學網站：<https://museum.hunglun.com>

給老師課堂使用，免註冊、免安裝。題目分國小、國中、高中三級難度。

工具：文物小百科、典藏搜尋（文物＋清代檔案）、猜猜哪個朝代、朝代排排站、分類闖關、翻牌配對、我的小展覽、史料探究、探險護照、老師專區（學習單、投影出題、搶答計分板、課程包）。

## 資料來源與授權

- 國立故宮博物院院藏文物 16 類（約 10.9 萬件）與清代檔案 9 類（約 39.6 萬件），來源為[政府資料開放平臺](https://data.gov.tw/)，依政府資料開放授權條款使用。
- 文物圖像：故宮開放之低階圖像以「公眾領域貢獻宣告」（CC0）規範；本站將其縮小後自行存放。
- 文物文字：國立故宮博物院，臺北，CC BY 4.0 @ www.npm.gov.tw。
- 精選 999 件名品的白話介紹（`data/ai_plain.json`）由 AI 依故宮說明改寫，逐件查核數字與朝代沒有超出原文，網站上標示「AI 改寫」並附故宮原文。
- 本站非國立故宮博物院製作。

## 架構

一支 Cloudflare Worker 提供網頁（`public/`）、API（`src/api.ts`）、照片（`src/img.ts`，R2）與每月檢查（`src/check.ts`）。資料存在 D1，搜尋用 FTS5（中文自己切成單字＋兩字一組，見 `tools/tokens.py`、`src/tokens.ts`）。

資料整理在本機跑（`tools/`）：下載 → 朝代正規化 → 產生 SQL 匯入 D1；照片抓取 → 轉 webp → 上傳 R2。

## 開發

```
npm install
npm test                         # 離線測試：朝代正規化、搜尋切詞、年號換算
npx wrangler dev                 # 本機啟動
```
